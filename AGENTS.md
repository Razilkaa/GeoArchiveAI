# Repository rules

- Один запуск полного отчёта: `pipeline/job_worker.py`.
- Один запуск карты: `services/map_digitizer/pipeline.py`.
- UI не читает файлы напрямую, только FastAPI.
- RAG выполняется только через RAGFlow; локальный BM25 не добавлять.
- `runs/` содержит внутреннее состояние и не коммитится.
- Пользовательские результаты публикуются в `results/`.
- Альтернативные алгоритмы не добавлять рядом с production-кодом: успешный
  эксперимент должен заменить существующий этап.
- Перед изменением геометрии проверять лист 21 фонда 384092 визуально.
- Для обычной разработки достаточно smoke-проверки изменённого маршрута;
  исторический большой набор тестов находится во внешнем архиве.
