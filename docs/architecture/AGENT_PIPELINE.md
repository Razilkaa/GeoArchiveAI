# Агентный конвейер

Пользователь загружает архив или выбирает ранее обработанный отчёт. Оркестратор ведёт единое задание и передаёт специализированным агентам только подходящие материалы.

1. **Агент-классификатор** распаковывает архив, определяет тома, текстовые страницы, карты, разрезы, таблицы и служебные листы.
2. **RAG-агент** выполняет OCR текстовых томов, индексирует доказательства и извлекает структуры, скважины, горизонты и выводы.
3. **Картографический агент** использует готовые open-source инструменты для сегментации, векторизации и подготовки геоданных.
4. **QC-агент** сопоставляет одинаковые сущности между текстом, картами и таблицами; конфликтующие значения не проходят в итог без проверки.
5. **Агент экспорта** собирает проверенные результаты в GeoPackage, GeoJSON и отчёт с происхождением каждого факта.

LLM управляет задачей и разбирает неоднозначности. Детерминированные инструменты отвечают за OCR, геометрию, координаты и форматы данных.

Текущая реализация оператора находится в `pipeline/report_orchestrator.py`. Формат результата картографического адаптера зафиксирован в `pipeline/contracts/map_agent_result.example.json`.
