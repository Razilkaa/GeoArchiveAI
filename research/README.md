# Research archive

Эта директория хранит воспроизводимость прошлых экспериментов, но её код не
вызывается FastAPI или рабочим pipeline.

- `legacy_pipeline/` — одноразовые OCR/CV/VLM-скрипты ранних итераций.
- `map_digitization/` — детекторы, трассировщики и локальные результаты карт.

Новый продуктовый код сюда не добавляется. Удачный эксперимент переносится в
`services/` с контрактом и тестами.
