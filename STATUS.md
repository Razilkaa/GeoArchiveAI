## Ключевые выученные уроки (для доклада)
1. VLM не умеет в координаты → CV находит, VLM читает (v1-фейл сохранён как слайд).
2. Классификация значений — по формату (регулярка), не по мнению VLM (совпадение всего 54%).
3. VLM галлюцинирует на обрезках → жёсткий промпт + context-кропы + перечитка подозрительных.
4. Ни один слой не эталон: отметки, подписи изогипс и текст отчёта валидируют друг друга.
5. «Пикеты» = порядковые номера станций; числа 2.72 = отметки глубин на пикетах (класс переименовать в depth_mark).

## СТРАТЕГИЧЕСКОЕ РЕШЕНИЕ по картам (14.07)
Вывод: тексты/RAG/агенты — наша сильная часть; карты самописной логикой — слабая.
Картографическую ветку переводим на готовые open-source инструменты (DARPA
CriticalMAAS + mapKurator), которые оборачиваем в тулы map-сабагента:

| Инструмент | Что заменяет/добавляет | Ссылка |
|---|---|---|
| mapKurator-spotter (UMN) | наш detector v4 + VLM-чтение: text spotting, обученный на картах, мультиязычный | github.com/knowledge-computing/mapkurator-spotter |
| Uncharted TA1 / LARA (MIT) | сегментация листа (карта/легенда/штамп), метаданные, точки, георепривязка, текст; CLI + REST + Docker — готовые тулы для агента | github.com/DARPA-CRITICALMAAS/uncharted-ta1 |
| DIGMAPPER: LDTR | трассировка ЛИНЕЙНЫХ объектов (разломы 0.88/0.95) — недостающее звено для изогипс; обучаем на синтетике при необходимости | arxiv.org/html/2506.16006v1 |
| ICDAR MapText evaluation | стандартные метрики; сравнить наш v4.1 vs mapKurator на нашей ручной разметке | github.com/icdar-maptext |

Оговорки: модели обучены на англоязычных картах USGS/Rumsey — на советском
чертёжном шрифте возможна просадка (тогда fine-tune на синтетике «ГОСТ-стиля»);
их георепривязка требует коорд. сетки/топонимов — наш путь через номера профилей
остаётся; проверить лицензию mapKurator.

Наше уникальное, что сохраняется поверх чужих тулов: классификация значений по
формату, QC-перекрёстки (шрифт/поверхность/подписи/текст отчёта), разметка и
валидационная методика, знание советских карт.

## ТРАССИРОВКА ИЗОГИПС (прорыв 15.07 ночью)
Классический трассировщик `pipeline/tracing/trace_isolines.py` (~200 строк, без
нейронок) на 1-битных BMP из «Том 2, 3 (выборка)»: мелкие компоненты (текст,
засечки, штриховка) отпадают по размеру -> Hough вычитает прямые (профили,
рамка) -> скелетизация -> обход в полилинии -> трёхуровневая сшивка (узлы 6px /
зазубрины 45px / разрывы подписей 130px) с проверкой коллинеарности мостика.
v5.1 (15.07): + сцепка пунктирных изогипс по направлению штриха (разломная
штриховка не сцепляется — штрих поперёк цепочки), + 4-й ярус сшивки 210px/0.985,
+ порог компонент 200->110 (средние обрывки между подписями).
- Лист 21 (плотный): 96 полилиний, ~35.6k px (х1.9 к v1), recall ~55-60%,
  precision геометрии ~100% (всё лежит на туши по построению).
- **Лист 23 (Шеинская пл., 1:100000): 101 полилиния, 62k px — почти полная
  оцифровка пучка изогипс антиклинали, ВИТРИННЫЙ КЕЙС.** Шеинская = структура,
  сданная в бурение по изогипсе -3800 (текст, стр. 118) — сюжет
  «текст->карта->проверка замыкания».
- 1-битные BMP из выборки лучше JPG для трассировки (уже бинаризованы).
- Выход: `out/<лист>/isolines.json` (полилинии, пиксели) + overlay.png.

## ДВУХКАРТОЧНАЯ СХЕМА (автономная ночная смена 15.07) — РАБОТАЕТ
`surface_crosscheck_23.py`: карта A (изогипсы с подписями) x карта B (RBF-поверхность
по 431 отметке глубин с ЭТОГО ЖЕ листа) -> вердикт каждой кривой:
- **main 17** (подпись и поверхность согласны в пределах шага) — сплошные;
- **combo 28** (расхождение 1-1.5 шага или один источник) — пунктир;
- **flagged 6** (>1.5 шага: чужая подпись или неверная сшивка) — красные «?»;
- **18 серых кривых получили значения от поверхности** (штрих-пунктир со «*»),
  и на СЗ-валу они совпали с авторскими подписями, которые не привязывались, —
  перекрёстная валидация подтверждена.
Результат: `out/23/combined_23.png`, `crosscheck_23.json` (вердикты + происхождение
каждого значения). Диагностика: у уверенных кривых label-vs-surface без
систематики (медиана -0.35 шага); большие расхождения = ошибки привязки, ловятся.

Не закрыто: свод антиклинали недотрассирован (замыкание -3.8 не проверить);
цифры структур 1/2 — ОДИНОЧНЫЕ символы, детектор требует >=2 компонент в группе
(нужен спец-проход для изолированных крупных цифр); цветовая шкала — инвертировать
под геологическую конвенцию (свод тёплым).
