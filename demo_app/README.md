# GeoArchive AI UI

Пользовательский экран оркестратора архивных геолого-геофизических данных.

## Возможности

- выбор ранее обработанного отчёта;
- локальная загрузка нового архива в `reports_inbox/`;
- предварительная классификация содержимого ZIP без распаковки;
- просмотр извлечённых структур, скважин и исходных материалов;
- поиск по выбранному отчёту через backend с контролем источников.

Новый архив по умолчанию не передаётся внешним моделям. Разрешение сохраняется рядом с архивом в отдельной policy-записи.

## Запуск

```powershell
cd C:\FINAM\Conference\demo_app\backend
python -m uvicorn api:app --host 127.0.0.1 --port 8765

cd C:\FINAM\Conference\demo_app
streamlit run app.py --server.port 8501
```
